# Design-source workflow

Produce:
- reference viewport/frame
- layout regions and anchors
- reusable token candidates (spacing, radius, typography, color, shadow)
- component/state inventory
- image aspect ratios and crop behavior
- responsive evidence actually present in the source
- VISUAL_SPEC.json geometry only for important anchors

Mark each field as exact, measured, or inferred when that distinction matters. Do not infer hidden mobile layouts from a desktop screenshot.
