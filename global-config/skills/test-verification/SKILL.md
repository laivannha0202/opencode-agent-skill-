# Test Verification

Detect package manager and scripts from repository files. Run the narrowest relevant check first, expanding to targeted tests, typecheck, lint, affected build or full suite when justified. Fix failures caused by the change. Never weaken valid tests to make code pass. Report passed, failed and not-run checks accurately.
