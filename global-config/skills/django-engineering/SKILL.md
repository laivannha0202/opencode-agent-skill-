# Django Engineering

Inspect settings/app structure and migration state. Use ORM efficiently and watch N+1. Keep authorization server-side. Preserve DRF serializer/viewset/permission conventions. Create migrations for schema changes; do not casually edit applied migrations. Test affected behavior.
