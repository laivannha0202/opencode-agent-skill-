# Dependency Management

Identify package manager, lockfile, runtime/framework versions and why the change is required. Prefer the smallest compatible version change, check peer/runtime compatibility, and update lockfiles through the package manager. Avoid broad upgrades during unrelated fixes. Verify install/build/tests.
