# Performance Engineering

Measure or inspect before optimizing. Look for repeated calls, N+1 queries, unnecessary rerenders, unbounded data, blocking work, oversized assets/bundles, missing useful caching and resource leaks. Prefer low-risk changes with measurable or strongly evidenced impact. Avoid premature micro-optimization.

Read [workflow.md](references/workflow.md) when the task reaches domain-specific behavior, compatibility, failure, or verification boundaries.
