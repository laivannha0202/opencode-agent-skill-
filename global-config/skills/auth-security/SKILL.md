# Auth Security

Verify authentication vs authorization, server-side permission enforcement, password hashing, session/token lifetime/invalidation, cookie/CSRF/CORS where relevant, input validation, object-level authorization, secret handling and safe redirects. UI hiding is not authorization. Do not weaken controls to fix development friction.
