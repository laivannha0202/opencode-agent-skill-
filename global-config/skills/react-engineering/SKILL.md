# React Engineering

Detect framework/version and project patterns. Keep render logic straightforward, avoid duplicated derived state, use effects only for external synchronization, stable list keys, existing state/data libraries, and loading/empty/error handling. Preserve component boundaries unless change is justified. Avoid premature memoization.
