# Bug Diagnosis

Capture the exact symptom. Locate the origin instead of patching symptoms blindly. Form a small set of plausible causes and verify them using code, logs, types, versions, tests or reproduction evidence. Apply the smallest root-cause fix, rerun the failing check, and inspect adjacent behavior. Do not randomly upgrade packages, delete lockfiles, clear caches, or disable checks without evidence.
