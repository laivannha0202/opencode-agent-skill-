# Git Safety

Start with git status and relevant diffs. Never discard uncommitted work unless explicitly requested. Do not hard reset, clean, force push or rewrite history without explicit intent. Stage only task-related files. Avoid committing secrets/build noise. Verify before commit when practical. Never claim push success unless it happened.

Read [workflow.md](references/workflow.md) when the task reaches domain-specific behavior, compatibility, failure, or verification boundaries.
