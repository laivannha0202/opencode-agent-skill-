# React Native Engineering

Detect RN version, Expo vs bare, JS/TS, navigation/state/data libraries and native structure. Follow existing component/style conventions, respect platform differences, handle remote states, avoid unnecessary effects. For Android build failures inspect JDK/Gradle/AGP/SDK compatibility before cache-clearing. Verify with existing checks.
