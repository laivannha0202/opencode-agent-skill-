# Code Review

Review in order: correctness/data loss; security/auth; API/schema/types; errors/edge cases; state/races; plausible performance; maintainability; missing verification. For each material finding include file/location, problem, impact and practical fix. Separate confirmed bugs from risks. Do not nitpick formatting.
