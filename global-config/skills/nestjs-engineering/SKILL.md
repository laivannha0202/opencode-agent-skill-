# Nestjs Engineering

Respect module boundaries and DI. Keep controllers thin and business rules in existing services/domain layers. Use DTO validation consistently. Enforce auth with guards/policies. Preserve exception/response conventions and OpenAPI patterns if present.

Read [workflow.md](references/workflow.md) when the task reaches domain-specific behavior, compatibility, failure, or verification boundaries.
