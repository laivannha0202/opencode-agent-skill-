# Ui Ux Engineering

Inspect the existing design system first. Check hierarchy, responsive behavior, spacing/typography, forms/validation, loading/empty/error/success states, keyboard/focus basics, image fallbacks, overflow/long text and component reuse. Use common interaction patterns without pixel-copying proprietary products.

Read [workflow.md](references/workflow.md) when the task reaches domain-specific behavior, compatibility, failure, or verification boundaries.
