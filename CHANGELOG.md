# Changelog

All notable changes to this project will be documented here.

The project follows Semantic Versioning.

## [1.0.0] - 2026-09-18

### Added
- Native OpenCode V2 plugin package.
- Automatic registration of packaged engineering skills.
- Automatic Build-agent engineering workflow injection.
- Namespaced commands: `/ues-fix`, `/ues-feature`, `/ues-review`, and `/ues-audit`.
- GitHub/npm-compatible package metadata.
- CI typechecking and tests.
- Native OpenCode lifecycle support through `opencode plugin add/check/update/remove`.
