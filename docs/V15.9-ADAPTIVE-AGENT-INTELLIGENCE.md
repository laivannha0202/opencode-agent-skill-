# V15.9 — Adaptive Agent Intelligence

V15.9 turns the V15.8 measured runtime into a model-aware, policy-compiled agent interface without weakening existing safety, evidence or verification gates.

## Scope

1. **Model-Specific ACI Compiler V1** — Adaptive Runtime Profile V3 compiles model surface, tool budget, skill metadata budget, context ABI, output budget, delegation breadth and verification policy from measured/configured model evidence.
2. **Deterministic Context Rehydration V1** — durable compaction state is rebuilt from deterministic artifacts and emitted with a rehydration manifest. Model-generated summaries are advisory only.
3. **Universal Tool Output Governor V1** — non-write child tool results share a reversible output boundary. Raw output is preserved in Evidence Store while the model sees a bounded typed reduction.
4. **Policy Lattice + Visibility Compiler V1** — policy precedence is compiled before tool exposure; deterministic denies are removed from the model-visible surface while runtime resource checks remain authoritative.
5. **Diversity-Aware Verification V1** — high/critical verifier roles prefer a distinct capability-eligible model when available; otherwise they use a fresh independent context and different role/tool constraints.
6. **Skill Activation Eval + Skill Diet V1** — selected skills remain metadata/budget bounded and a deterministic activation eval measures precision/recall before any diet/promotion decision.
7. **Decision Replay + Context Observatory V1** — runtime traces include profile decision IDs and model-visible context estimates. CLI can emit a side-effect-free replay packet; replay never executes tools.
8. **Role Context ABI + Lifecycle Hook ABI + Scaffold Attenuation** — verifier/critic roles are read-only and do not receive executor rationale as evidence; standard lifecycle hook names are explicit; weaker models receive more scaffolding while stronger measured models receive less.

## Non-regression invariants

V15.9 does not weaken Evidence Store, Runtime Epoch ownership, dirty-work and local-.env guards, write checkpoints, process supervision, bounded verification timeouts, independent final verdicts, browser/visual evidence rules, post-run hygiene or real-model promotion gates.

Optimization is not promoted when correctness or verifier quality regresses. Real-model claims remain measured-only.

## New commands

- `ues context-report <trace-id> [dir]`
- `ues replay <trace-id> [dir] [--decision <decision-id>]`
- `npm run eval:skills:v15.9`
- `npm run eval:v15.9`

## Release gate

V15.9 requires deterministic tests plus the existing V15 regression suites. Real-model promotion still requires paired baseline-vs-UES evidence through `ues trial --require-promotion`.
