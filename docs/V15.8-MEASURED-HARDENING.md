# V15.8 Measured Hardening

V15.8 turns the V15.7 adaptive runtime into a stricter measured-hardening release. The goal is not to add more orchestration layers. The goal is to remove blind spots that can cause false optimization claims, Windows foreground-service hangs, provider-cache cross-contamination, or model-surface decisions based only on names.

## Command Intelligence V4

Command classification now unwraps common shell launchers before deciding whether a command is verification or a long-running service.

Supported wrapper forms include:

- PowerShell call operator: `& "C:\\Program Files\\nodejs\\npm.cmd" test`
- `cmd /c ...` and `cmd.exe /d /s /c ...`
- `powershell -Command "..."`
- `pwsh -Command "..."`
- `sh -c "..."`, `bash -lc "..."`, and `zsh -c "..."`

Nested verification pipelines are also inspected after unwrapping, so a command such as:

```powershell
powershell -Command "npm test | Select-String FAIL"
```

keeps the bounded verification timeout and hidden-output finding.

Bun is treated as a package-manager surface for `bun test`, `bun run dev`, and filtered/workspace-style scripts. Long-running service scripts are redirected to the managed-service lane instead of being allowed to block a foreground child.

## Real A/B Telemetry V2

Pi-native evaluation now captures the first provider usage sample in addition to aggregate usage. This activates the initial-context inflation check that was previously present in benchmark confidence but could remain unmeasured.

A paired real-model evaluation may now be run as a hard promotion gate:

```cmd
ues trial --require-promotion --model provider/model
```

The gate fails closed when required input/token telemetry is absent. Deterministic release tests still do not claim real-model quality improvement.

## Provider Cache Stability V2

Cache learning is scoped by:

```text
provider + model + usage-accounting schema
```

rather than model name alone. This prevents two providers exposing the same model identifier from sharing incompatible cache behavior.

The policy also uses bounded hysteresis. A previously measured cache/token mode is not flipped by a small number of borderline observations. Stable-prefix history remains immutable; only newly produced live-zone visibility is adjusted.

## Model Runtime Profile V2

Runtime surface selection now uses this evidence order:

1. measured model/task performance when the configured sample threshold is met;
2. configured model capabilities;
3. model-name heuristic fallback.

The selected thinking level is never lowered by this profile. The profile only bounds orchestration surface such as advertised tools and read parallelism.

## Safe adaptive behavior

V15.8 keeps auto-adjustment on low-risk orchestration surfaces only:

- tool-choice surface;
- bounded read parallelism;
- live-zone output visibility;
- cache presentation policy;
- command-aware compaction budgets.

The runtime does not auto-disable or weaken:

- independent verification;
- security/permission guards;
- Evidence Store raw evidence;
- dirty-work/local-env protection;
- destructive-command policy;
- the user-selected thinking level.

Runtime Waste Learner remains evidence-producing rather than self-modifying correctness policy.

## Release and promotion evidence

`npm run release:verify` remains the deterministic package release gate and now includes `eval:v15.8`.

Real-model performance remains a separate evidence layer. `--require-promotion` must be used when a release or optimization is being promoted on claims about real-model quality or efficiency.

GitHub Actions runner/account failures that stop before step execution are infrastructure failures, not code-test evidence, and must be resolved separately before claiming cloud CI coverage.

## Regression coverage

`test/v15-8-runtime.test.mjs` locks:

- Windows/POSIX shell-wrapper unwrapping;
- hidden pipelines inside wrappers;
- Bun verification/service routing;
- provider-scoped cache learning;
- cache hysteresis;
- measured/configured model-profile precedence;
- fail-closed real-model promotion when usage evidence is absent;
- presence of first-usage and hard-promotion plumbing in the Pi evaluator.
